## ⚙️ Ejecutar el proyecto

Clona el repositorio:

```bash
git clone https://github.com/TU-USUARIO/TU-REPOSITORIO.git
```

Ingresa al proyecto:

```bash
cd TU-REPOSITORIO
```

Instala las dependencias:

```bash
npm install
```

Ejecuta Angular:

```bash
ng serve
```

Después abre:

```text
http://localhost:4200
```
